二、这次修了 3 个模块
------------------------------------------------------

【模块一】数据干扰拦截 + 菜名清洗

  1) 前台系统噪音
     现象：出现一道叫「주문자」或「주문전용」的假菜
     原因：주문자:주문전용 2026-11 这种单据元信息被当成菜品行
     修复：NoiseLineFilter 新增系统噪音词表
           주문자 / 주문전용 / 주문접수 / 주문번호 / 영수증 / 매출
           去掉所有空格后 contains 命中 -> 整行丢弃
           所以「주 문 자 : 주 문 전 용」这种对齐空格排版也能拦

  2) 菜名追加后缀
     现象：향라오징어 1 추가 查不到中文，显示成未命中的黄点
     原因：词典里没有带「추가」后缀的条目
     修复：TextNormalizer.cleanDishName()，正则 行尾 [0-9]* 추가
           在 MenuDictionary.lookup 之前先剥掉行尾追加描述
           实测：
             향라오징어 1 추가   -> 향라오징어
             향라오징어 2추가    -> 향라오징어
             향라오징어추가      -> 향라오징어
             마라쇼롱샤 추가요리 -> 原样保留（只吃行尾，不动中间）
             명품양갈비 -1취소   -> 原样保留（취소 由取消单链路处理）

【模块二】卡片状态栏置顶（防遮挡）

  旧结构：列表在上，状态栏在底部 -> 菜品多时列表内部滚动，状态栏被滚出视野
  新结构：状态栏是 Column 的第一项，列表是第二项（独立滚动）
          ┌──────────────────────────┐
          │ 16号          17:00 03:21 │  <- 固定，永不被遮
          ├──────────────────────────┤
          │ 菜品 / 饮品（这里滚动）    │
          └──────────────────────────┘
  圆角：状态栏加 clip(RoundedCornerShape(topStart=12, topEnd=12))，与 Card 圆角严丝合缝

【模块三】主界面去黑边

  旧版：顶栏 48dp，横屏 411dp 高度直接吃掉 12%，第一排卡片被顶下去
  新版：Box 叠放
          Box(fillMaxSize + safeDrawingPadding + 横向 12dp)
            |- OrderGrid(fillMaxSize, contentPadding top = 2dp)
            |- Row(align = TopEnd)  状态灯 + 历史 + 设置
  控制条带半透明底，浮在卡片右上角
  第一排卡片现在几乎贴着屏幕上沿

三、验证方法
------------------------------------------------------
1. 让前台打一张带 주문자:주문전용 的单
   -> 不应出现「주문자」假菜，正常菜品照常上屏
2. 点一道菜加「추가」（追加）
   -> 卡片上应显示中文翻译，不再有黄点
3. 让一张单有 15 道以上菜（超过半屏）
   -> 卡片高度封顶在屏幕一半，内部滚动
   -> 桌号和时间始终在卡片顶部可见，不随滚动消失
4. 看主界面第一排卡片
   -> 应紧贴屏幕上沿，右上角三个小控件悬浮其上

四、排障
------------------------------------------------------
还有假菜           把该行原文发我（设置 -> 连接状态 -> 日志），加进 SYSTEM_NOISE_TOKENS 即可
追加菜仍不翻译     确认是「추가」结尾；若是「추가요리」这类正常菜名，需要在 MenuTable 补词条
状态栏仍被遮       确认装的是 4.2.0；旧版结构不同
第一排仍被顶下去   若是刘海屏，safeDrawingPadding 会留出刘海高度，属正常安全区
